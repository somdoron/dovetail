# Dovetail 0.1.2

## YAML configuration reading

Add project `standard-yaml`, exposing package `standard.yaml`, for reading YAML
configuration into application types. `Yaml.parse` produces a source-located
value tree; `@derive(YamlDecoder)` generates strict decoders for records, enums,
newtypes, and generic types. Missing or null optional fields become `None`, while
unknown fields, duplicate keys, and invalid types produce structured errors with
field/index paths and source locations.

The reader supports block and flow collections, quoted and plain scalars,
multiline strings, YAML 1.2 Core scalar resolution, and exact `Int64` values.
It accepts one document and limits nesting to 128 collection levels. Encoding,
anchors, aliases, explicit tags, directives, complex keys, and document streams
remain outside the supported subset.

See the [YAML library guide](../../website/content/book/22-stdlib.md#2211-yaml)
for a complete example and supported input details.

## Compiler fixes

- Prevent return-type context from leaking into trait implementations generated
  by derives, including JSON decoders using associated types.
- Preserve bound generic parameters when inferring enum constructors such as
  `Ok(value)`. Unused covariant parameters still default to `Never`, but a known
  caller type parameter is no longer replaced by that default.

## Version compatibility

The compiler and VS Code extension are both version **0.1.2**. Update
`compiler-version = "0.1.2"` in application and dependency manifests when moving
to this release; Dovetail requires an exact compiler-version match. Use the
matching standard-library revision. Refresh installed AI guidance with
`dovetail ai install` after upgrading the compiler.
