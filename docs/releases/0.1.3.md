# Dovetail 0.1.3

## Strict JSON integer decoding

`Int32.fromJson` and `Int64.fromJson` now reject fractional stored numbers with
`JsonError.NonIntegralNumber`, rather than silently truncating them. Out-of-range
values, infinities, and NaN return `JsonError.OutOfRange("Int32")` or
`JsonError.OutOfRange("Int64")` instead of trapping during conversion. Derived
record decoders inherit these checks for ordinary integer fields.

This changes decoding behavior for callers that relied on truncation. Exhaustive
matches on `JsonError` must handle the two new variants. `Json.Number(Float64)`
and floating-point decoding remain unchanged.

## Integer precision limitations

The JSON tree still stores numbers as `Float64`. These checks cannot recover
precision lost during parsing or encoding, or detect a fractional input that has
already rounded to an integer. Not every `Int64` survives a complete JSON wire
round trip: `Int64.MAX` and `9007199254740993` fail, while `Int64.MIN` passed the
targeted regression investigation. Derived encoders and decoders share these
limitations; this release does not remove the need for a custom exact-integer
representation when full-range round trips are required.

A validated text-backed numeric variant is proposed in the
[exact JSON integer design](../json-integer-design.md), but is not implemented in
this release. See the [JSON library guide](../../website/content/book/22-stdlib.md#228-json)
for the current API contract.

## YAML regression coverage

Additional tests verify exact integer decoding at the `Int64` boundaries and
around ±2^53, including derived record fields, typed overflow errors, and rejection
of decimal/exponent float nodes for integer targets. YAML already preserves
integer tokens exactly; its behavior and representation are unchanged. YAML has
no encoder.

## Version compatibility

The compiler and VS Code extension are both version **0.1.3**. Update
`compiler-version = "0.1.3"` in application and dependency manifests when moving
to this release; Dovetail requires an exact compiler-version match. Use the
matching standard-library revision. Refresh installed AI guidance with
`dovetail ai install` after upgrading the compiler.
